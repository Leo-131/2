# 通用自动化客户开发技能

插件包版本：1.1.0；工作流首次发布版本：1.0.0

根据品牌、产品或服务类目、目标市场和合作模式匹配潜在客户，完成客户研究、联系人核实、开发信准备，以及有实际工具和用户授权时的发送、跟进和进度记录。

## 文件

- `SKILL.md`：技能触发说明、配置字段、执行流程和证据要求。
- `README.md`：使用及接入说明。

## 使用

在可以访问本仓库文件的助手中，要求读取并执行 `skills/automated-customer-development/SKILL.md`，例如：

> 请按照通用自动化客户开发技能执行：品牌为 Example，官网为我提供的地址，产品为家居收纳用品，目标市场为德国，寻找 20 家进口商和分销商。本次完成客户研究并生成德语开发信草稿。排除名单见附件。

建议提供：品牌或供给主体、官网及产品资料、产品或服务类目、目标地区、合作模式、客户类型、目标数量、排除名单，以及本次需要研究、草稿还是实际触达。多品牌和多类目会分别建立配置。

## 安装与接入

本仓库现在同时提供技能源码、插件清单、GitHub 插件目录和 ZIP 插件包，详见根目录 README。打包完成不代表已安装到账号或更新了原 FLEXTAIL 插件。

- 支持 `SKILL.md` 的宿主：将本目录放入该宿主明确支持的技能目录，按宿主要求重新加载并确认技能出现在可用列表中。
- 接入已有插件：将本目录加入插件源码，按该插件平台的真实清单格式注册、打包和发布。不能仅靠推送 GitHub 就认定远程插件已更新。
- 当前会话直接使用：让助手读取仓库中的 `SKILL.md` 并按其流程执行，无需声称已安装。

技能说明不会自动提供搜索、CRM、邮件账号或调度器。实际发送需要可用的发送工具和用户明确授权；定时跟进需要可用的调度工具。没有这些能力时，仍可交付研究、草稿和本地记录。
